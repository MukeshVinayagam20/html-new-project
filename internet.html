How the Internet Works

The net more than 5X109users. Every page you open travels across thousands of kilometers of cable in milliseconds.

1. Clients and Servers

Your browser is a client.It asks a server for a file, and the server replies with HTML,images and other resources.

What is an IP address?

Every device has an address,for example:

192.168.1.10(IPv4)

2001:db8::1 (IPv6)

2.DNS - The Phone Book

DNS turns a name like google.com into an IP address so your computer knows where to go.

3.HTTP and HTML

The browser uses HTTP to fetch a page. Water is H2O; the web is HTML.Every page starts like this:

<!DOCTYPE html>
<html lang="en">
<head>
   <title>Page</title>
</head>
<body></body>
</html>

The browser reads these tags and draws the page on your screen.
